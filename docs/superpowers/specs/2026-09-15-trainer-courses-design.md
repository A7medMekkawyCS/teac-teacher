# Trainer Courses + Arab Universities

## Decisions
- Teacher mode extends to: حصص · كورسات · الاتنين
- Course format: recorded lessons + optional live sessions
- Country-first filter; Egypt default; other Arab countries listed for expansion
- Prototype UI in App.tsx + catalog modules (no real LMS backend)

## Surfaces
- Student/uni: كورسات browse, detail, enroll, my courses
- Teacher: my courses, create course, lessons, live schedule, publish
- Setup: country selection; uni catalog filtered by country
